[Zed](https://zed.dev/) is a high-performance open source code editor that offers vim mode, integrated terminal, themes and a whole lot out of the box. Here are 10 Keyboard Shorcuts you need to know:

### Toggling Docks

Use `⌘ B` to toggle the left dock to view your files or `⌘ J` to toggle the bottom dock for the integrated terminal.

### Working with the Integrated Terminal

Use `` ⌃ ` `` (option and backquote) to open the integrated terminal, `⌃ ~` (option and tilde) to open a new tabs or `⌥ ⌘ T` to close all other terminal tabs (which also works for normal file tabs).

### Using the Command Palette and Install Zed CLI

Use `⌘ ⇧ P` to open the command palette and install the Zed CLI to launch Zed from your terminal using `zed .`.

### Working with Project Files

Use `⌘ P` to search and open any project file.

### File Search

Use `⌘ F` to search within a project file and `⌘ G` to navigate search matches.

### Project-Wide Search

Use `⌘ ⇧ F` to open project-wide search, `⌘ G` to navigate search matches and `⌥ ↵` to jump to a file.

For more on Zed, visit [zed.dev/features](https://zed.dev/features) to learn more.
